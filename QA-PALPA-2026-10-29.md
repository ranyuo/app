# Verificación del portal Palpa — 29/10/2026

Validación en el entorno local, con PHP 8.3, MariaDB y Playwright/Chromium, usando exclusivamente la base desechable `nasca_test`. No acredita despliegue, correo ni autenticación en servicios externos.

| Comprobación | Resultado |
| --- | --- |
| `node tests/palpa-content.cjs` | Cinco programas, 231 unidades, 34 personas, 32 becarios, 31 tasas, 30 estadísticas; hashes y tamaños de 48 recursos correctos |
| `php tests/demo-validation.php` | 179 registros validados, cero fallos |
| `php tests/run.php` | 31 comprobaciones de instalación, autenticación, persistencia, privacidad y trámites aprobadas |
| `php tests/parity.php` | 51 comprobaciones de roles, permisos, módulos académicos, documentos y bolsa laboral aprobadas |
| `php tests/palpa-import.php` | 37 comprobaciones de importación, respaldo, conservación de usuarios/datos/IDs, programas retirados y privacidad aprobadas |
| `php tests/functional-fixes.php` | 41 comprobaciones de normalización, actualización idempotente y conservación de cuentas aprobadas |
| `node tests/browser-palpa.cjs` | 67 comprobaciones aprobadas sobre 31 rutas, cinco programas, módulos, descargas, resolución, búsqueda y móvil; cero errores JavaScript |
| Sintaxis | Archivos PHP de `portal-private/` y `public_html/` correctos; JavaScript de integración y prueba web correctos |
| `git diff --check` | Sin errores |

Las pruebas de funciones usan sus propios fixtures; no dependen de noticias reales ni de Contabilidad como oferta de Palpa. Se corrigió una variable fuera de alcance en la fixture de la oferta laboral de `parity.php`, conservando sus aserciones.

La prueba web detectó y permitió corregir el visor: su lista de recursos institucionales admitía solo Nasca y Chincha, por lo que un archivo de Palpa abría un PDF de ejemplo. Se añadió Palpa y se comprobó la navegación a la resolución real. También se verificaron las notas de matrícula 2026-I, las descargas y la ausencia de desbordamiento horizontal a 390 px.

La carga pública final de la base local se restauró con `PalpaContent::apply` después de las pruebas de importación. Los datos QA privados y cuentas de prueba pertenecen únicamente a esa base desechable; la carga inicial de `portal.json` no contiene esas cuentas ni datos operativos.

Capturas locales generadas por la prueba: `tests/.results/palpa/home-desktop.png` y `tests/.results/palpa/home-mobile.png` (ignoradas por Git). Los recursos oficiales y sus hashes están en `portal-private/data/palpa-sources.json`; las diferencias entre fuentes se describen en `MAPEO-PALPA.md`.
